# Code of Conduct

Status: active
Last updated: 2026-11-11
Summary: this project follows the Contributor Covenant, version 2.1, and says where to report unacceptable behaviour.

This project follows the Contributor Covenant, version 2.1. Its text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/> and applies to everyone taking part in this
repository's issues, pull requests and discussions.

To report unacceptable behaviour, use **Report a vulnerability** on this repository's Security tab
(<https://github.com/dlprentice/onslaught-godot/security/advisories/new>). The report goes privately to the maintainer.
